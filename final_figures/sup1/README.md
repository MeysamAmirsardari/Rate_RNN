# Supplementary Figure 1 - ECoG global field power

This package preserves the spatially distributed GFP analysis formerly shown
in Figure 2B. It compares actual repetitions 1 and 15 at each deviant position.
Significance is assessed with the existing two-sided whole-block sign-flip
cluster-mass test, jointly corrected over time and all three recordings.

Build from the project root:

```bash
python -m final_figures.sup1.make_sup1
```
